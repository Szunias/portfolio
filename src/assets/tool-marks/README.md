# About tool marks

These marks identify tools used in the linked project examples. They are not
client logos, certifications or endorsements.

The two SVGs are exact copies of existing repository assets; their geometry,
viewBox and monochrome fill were not changed for this section:

- `unreal.svg`: `old/public/assets/icons/toolkit-svg/unreal.svg`.
  Unreal Engine's circular U mark. Brand reference:
  https://www.unrealengine.com/en-US/branding
- `unity.svg`: `old/public/assets/icons/toolkit-svg/unity.svg`.
  Unity's cube mark. Brand reference:
  https://unity.com/legal/branding-trademarks
  The linked official logo collection is
  https://brandfolder.com/s/fj5fnvgrqhwv9g9rtbrc3

Source review: 2026-09-05. These are existing local vector assets, not newly
downloaded files or newly drawn approximations. The upstream file provenance
before they entered this repository is not recorded.

Wwise and REAPER use plain text names. No new standalone official monochrome
product mark was verified during the bounded source search. In particular, an
Audiokinetic corporate logo must not be substituted for a Wwise product logo.

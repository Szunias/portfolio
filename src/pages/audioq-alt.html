AudioQ

Started 2024 · public v1.0.0, 9 November 2025 · Solo C++ and JUCE · C++17 · JUCE 8 · MIT

AudioQ is a sampler plug-in. It loads a sound, turns any part of it into a loop and reshapes the playback with granular mode and effects.

I built it alone in C++ and JUCE. I wrote the waveform editor, playback engine and custom effects; the filters and compressor use JUCE DSP components.

Source on GitHub ↗ Recorded demo ↗

Loading a sound and looping it

AudioQ loads WAV, AIFF and MP3 files. Dragging across the waveform sets the loop region, and a crossfade smooths its join. The 20–300 BPM control changes playback speed; it does not time-stretch the file to a detected tempo.

The order the controls run in

Granular mode changes the source playback before the sound reaches the effects. JUCE supplies the TPT filters and the compressor; I wrote the rest.

  1. Source file and loop region
  2. Playback speed or granular mode
  3. Filters
  4. Compressor
  5. Tremolo, bitcrusher and glitch
  6. Dry / wet output

The safety limit and what is still untested

If an output block exceeds 4.0 linear amplitude, the processor clears that block and flags a warning. This check silences the affected block; it does not limit its peaks.

I rebuilt the plugin more than once before the public release. The download is a Windows VST3 build. The source also builds a standalone app, but broader testing across hosts, operating systems, sample rates and channel layouts is still pending.

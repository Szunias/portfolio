UE Rebuilder v7

A Windows utility for cleaning, rebuilding and diagnosing Unreal projects. Version 7 is a Python rewrite with build, packaging, health-check, plugin and backup tools.

Tool developer · Python application bundled as an executable

Build and cleanup

One interface for the repeated Unreal maintenance path

Total Rebuild cleans generated folders, regenerates project files and rebuilds the project. Smart Clean previews folder sizes before removal. Packaging actions create development or shipping builds.

The application detects supported UE4 and UE5 installations and keeps a timestamped operation log, so cleanup, generation and build failures remain visible instead of disappearing behind a single button.

Diagnostics and management

Health checks, plugins and disk usage

Health Check and Auto-Repair cover common project problems. The application also includes disk-usage inspection, a plugin manager, launch options, process cleanup and log access.

Create Backup is a separate, user-triggered action. Total Rebuild does not automatically create an archive, so the page keeps those actions distinct.

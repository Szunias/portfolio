UE Rebuilder v7

A Windows utility for cleaning, rebuilding and diagnosing Unreal projects. I rewrote version 7 in Python and bundled it as an executable.

Solo tool developer · Python

Application

Cleanup, builds and project diagnostics

The app detects supported UE4 and UE5 installations, previews generated-folder sizes before cleanup and records every operation in a timestamped log.

Separate controls clean generated folders, regenerate project files, rebuild the project and create development or shipping packages.

Backups remain a separate user-triggered action; Total Rebuild does not create an archive automatically.

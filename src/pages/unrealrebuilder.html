UE Rebuilder v7

UE Rebuilder v7 puts common Unreal maintenance in one Windows app. I rewrote it in Python so users can clear generated files, recreate project setup, run builds and package a project for testing or release.

Solo tool developer · Python

Application

Common Unreal maintenance in one app

The app finds supported UE4 and UE5 installations, shows how much space replaceable generated folders use before deleting them and records each operation in a dated log.

Separate controls let the user clean those folders, recreate project files, rebuild the project or make a package without running every step.

Backups remain a separate action started by the user. Total Rebuild does not create one automatically.

UE Rebuilder v7

A Windows utility for cleaning, rebuilding and diagnosing Unreal projects. I rewrote version 7 in Python and bundled it as an executable.

Solo tool developer · Python

Application

Cleanup, builds and project diagnostics

Total Rebuild cleans generated folders, regenerates project files and rebuilds the project. Smart Clean previews folder sizes before removal, while separate packaging actions create development or shipping builds.

The utility detects supported UE4 and UE5 installations and records each operation in a timestamped log. Health checks, common repairs, disk-usage inspection, plugin management, launch options and process cleanup are available from the same interface.

Backups remain a separate user-triggered action; Total Rebuild does not create an archive automatically.

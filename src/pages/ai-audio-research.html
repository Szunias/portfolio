Benchmark

Four generative configurations and a procedural DSP baseline

For the latency benchmark, I measured cold start, warm generation and end-to-end Unreal playback for standardised 0.5–2.0-second clips. Separately, I ran a 600-attempt quality matrix across the same five methods.

The test machine used an AMD Ryzen 9 7940HS, an RTX 5070 Laptop GPU with 8 GB VRAM, 64 GB RAM, Unreal Engine 5.4.4 and Python 3.11.7.

The figures on this page follow the final protocol documented in the published thesis. The benchmark measures this prototype, not model speed in isolation: it includes the request, local generation or network transfer, decoding and playback.

Playback strategy

Generate before the gameplay event

The server watches game state and queues likely sounds before they are requested for playback.

Approaching a door can queue door sounds; entering a forest can queue ambience. Generated results are stored under the request key, so a later event can play them without waiting for the model.

If the prediction misses, procedural DSP covers the event while the generated sample is prepared for a later request.

Pipeline Predict → generate off the critical path → cache → play → use DSP on a miss.

AutoTrim Exporter

2026 · AutoTrim 3.4.3 · Designer and developer · Lua ReaScript · ReaImGui · Windows, macOS and Linux

AutoTrim is a REAPER delivery tool that turns the layered items I select on the timeline into trimmed, named and verified audio files.

I designed and built the Lua and ReaImGui application and its render workflow: cross-track collection, rendered-signal analysis, delivery profiles, mandatory Preflight and export verification.

From selection to delivered files

  1. I select the item that defines the event.
  2. Select across tracks adds overlapping layers and ignores unrelated long items unless I select them.
  3. Mandatory Preflight reports blockers and any difference between monitoring and the render mode.
  4. Profiles, naming and version rules write the files, the history and a batch report.

Analysis runs on an unnormalised, uncompressed intermediate render. Delivered files can be WAV, FLAC, OGG or MP3.

Boundaries, fades and format

Adaptive silence finds the boundaries, with separate start and tail controls, a pre-roll and up to three render passes. Per-item delivery in 3.4.3 uses a time-selection window and native render fades, so takes, envelopes, stretch markers, source offsets and project timing are left alone.

A profile holds format, loudness rules, destination, naming and metadata, with starting points for game middleware, broadcast and streaming. The same screen carries WAV bit depth, RF64, channel policy, UCS naming and embedded metadata.

Preflight and History

Preflight separates export blockers from differences between monitoring and rendering, and its report can be copied. History keeps each file's path, length and Peak, RMS and LUFS-I measurements, with actions to show, play or copy it.

Project isolation
Every export stays bound to its project tab, and cleanup stays armed until restoration succeeds.
Files and Undo
New-version delivery refuses last-moment collisions and never silently replaces project source media. With backups on, Undo restores a replaced file and keeps newer work under a recovery name.

Release and requirements

The tour and screenshots are from the packaged 3.4.3 release, engine 2.11.4, recorded with synthetic audio, fictional file names and a dedicated demo project. The current download is 3.4.4, engine 2.11.5, published 10 August 2026: correctness and accessibility fixes on the same layout, so those screens still apply.

AutoTrim needs REAPER 7.37 or newer (64-bit) and ReaImGui 0.10.0.5 or newer in the 0.10 API series. SWS is optional.

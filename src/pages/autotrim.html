Select across tracks starts from one timeline item and collects the layers that belong to the same sound. Long background material is kept out unless the user selected it deliberately.

AutoTrim can render the selection as one layered asset or create one file per item. Delivery formats are WAV, FLAC, OGG and MP3, while the analysis path stays lossless.

Rendered-signal trimming

Measure the processed sound and keep its tail

AutoTrim analyses an unnormalised REAPER render, so item and take processing affect the measured boundaries. It does not guess from the untouched source file.

Start
A hard peak floor, local noise estimate and onset energy locate useful material without shaving off the attack.
Tail
A separate threshold, hysteresis and a decay-aware window keep reverb and effect tails from ending abruptly.
Padding
Pre-roll and extra tail remain explicit controls, with starting presets for one-shots, impacts and ambiences.
Protection
Material far longer than the intended sound set is excluded from automatic batch collection.

File safety

Check the render before it becomes a delivery

AutoTrim separates analysis files from the destination and commits the final result only after its length and output path pass validation.

  1. 01

    Analyse. One raw pass establishes the boundaries, with one optional extension pass when the tail needs more room.

  2. 02

    Render. The chosen format and level settings are applied once to the measured range.

  3. 03

    Commit. AutoTrim checks the file, records diagnostics and either creates a new version or replaces the requested delivery deliberately.

AutoTrim Exporter

I designed and built AutoTrim Exporter, a REAPER tool that turns layered sound effects into trimmed, named audio files and checks each delivery.

From selection to delivered files

A sound effect can span several tracks. AutoTrim collects those layers and prepares the export without rearranging the timeline.

  1. Select the item that defines the sound.
  2. Use Select across tracks to include overlapping layers while leaving unrelated long items out.
  3. Choose the delivery profile and review the Preflight checks.
  4. Render the files, with naming, versioning and a report for the batch.

Interface tour recorded in v3.4.3. The screenshots on this page show that version; current builds are in the release hub.

Delivery history and regression checks

History records each file’s path, duration and available Peak, RMS and LUFS-I measurements. Files can be played, located or copied from the list. Loudness measurement requires the optional SWS extension.

Project isolation
An export stays bound to the REAPER project tab it started from, including while restoring temporary render settings.
Files and Undo
New-version delivery refuses last-moment collisions and never silently replaces project source media. With backups on, Undo restores a replaced file.

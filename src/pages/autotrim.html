AutoTrim Exporter

I designed and built this REAPER tool for delivering sound effects.

Watch the interface tour Download the current release ↗ Release hub ↗

It gathers a sound’s layers from several tracks, trims the silence around them without cutting the attack or the tail, and verifies every render before the named file reaches the delivery folder.

Designer and developer. Lua ReaScript and ReaImGui, REAPER 7.37+ on Windows, macOS and Linux. Captured in v3.4.3; v3.4.4 keeps the same layout.

One sound across several tracks

Sound effects rarely sit on one track: an impact, its debris and a sub layer can be three items on three tracks, with a long ambience running underneath. I built Export around the item that anchors the sound.

Select overlapping collects the items on other tracks that overlap it, leaves the long ambience out and frames the result in the arrange view without moving anything on the timeline.

Trims that keep the attack and the tail

For a long tail that is still ringing, a third pass may scan up to 30 seconds.

Adaptive silence finds where a sound starts and where its tail ends, each against its own threshold, and widens both by a pre-roll and a safety ending so the attack and the decay stay whole.

Presets start from the kind of sound: one-shots, tails and impacts, or ambiences.

Level and format for a game delivery

A delivery keeps its original level or is levelled by LUFS‑I, RMS, Peak or True Peak under a true-peak ceiling. Quick targets cover a mobile game at −16 LUFS, streaming at −14 and EBU R128 at −23.

Peak and RMS are measured after export and stored with every verified delivery; LUFS‑I is added when the optional SWS extension is installed.

Game audio ships dry, and the middleware owns the final level.

So the Game / Wwise profile renders 48 kHz, 24‑bit WAV and leaves the level untouched. Positional sounds usually go out mono, so the channel policy is set per batch. A saved profile keeps format, loudness, destination, naming and metadata together.

Names can follow UCS 8.2.1, and each batch can get a delivery report with a verdict for every file.

Preflight before every export

A blocker, a setting that would make the delivered file wrong, stops the render.

Preflight says what the render will and will not pass through.

A second list names where the file will differ from what you hear in the session: a per-item render, for example, takes the media items directly and skips track, folder and master processing.

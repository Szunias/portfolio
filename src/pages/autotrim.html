AutoTrim Exporter

A REAPER delivery tool that turns layered timeline items into trimmed, named and verified audio assets.

I designed and built the Lua/ReaImGui application and its rendering workflow, including cross-track collection, rendered-signal analysis, delivery profiles, mandatory Preflight and export verification.

One selection becomes a checked delivery

Selection, analysis, Preflight, rendering and file delivery stay in one workflow, and the source project is restored to its pre-export state once delivery finishes.

  1. Anchor the sound Select the timeline item that defines the event and its initial range.
  2. Collect across tracks The “Select across tracks” option pulls in overlapping layers and leaves unrelated long items out unless you select them.
  3. Check before rendering Mandatory Preflight reports blockers and differences between monitoring and the selected render mode.
  4. Deliver and record Profiles, naming and version rules produce verified files, history and a per-batch report.

Analysis uses an uncompressed intermediate render. Final output can be WAV, FLAC, OGG or MP3.

Control the rendered sound and how it leaves the project

AutoTrim can measure an unnormalised intermediate render, then keep boundaries, fades, level, format, naming and metadata as explicit delivery choices.

Trim & fades · UI 3.4.3

Detect boundaries without rewriting source items

Adaptive silence uses independent start and tail controls, with pre-roll, a safety ending and one, two or three render passes. No trim delivers the selection without boundary detection.

For per-item delivery, 3.4.3 uses a time-selection window and native render fades, preserving takes, envelopes, stretch markers, source offsets and project timing.

Format & delivery · UI 3.4.3

One profile holds format, loudness, naming and metadata

Profiles capture format, loudness rules, destination, naming and metadata. Built-in starting points cover game middleware, broadcast and streaming deliveries.

The same screen exposes WAV bit depth, RF64 and channel policy, UCS naming, embedded metadata and the per-batch delivery report.

Check the render before it starts and keep its delivery trail

Preflight · UI 3.4.3

Show what the render will and will not contain

Preflight separates export blockers from signal-chain differences between monitoring and rendering, with a report that can be copied for review.

History · UI 3.4.3

Inspect each verified file

History stores the output path, length and Peak, RMS and LUFS-I measurements, with actions to show, play or copy each delivery.

Project isolation. Every export stays bound to its source project tab, and unfinished cleanup remains armed until restoration succeeds.

File and Undo safety. New-version delivery refuses last-moment collisions and never silently replaces project source media. With backups enabled, Undo restores a replaced file while preserving newer work under a recovery name.

AutoTrim Exporter

A REAPER tool for sound designers who need to turn layered timeline items into trimmed, named and ready-to-deliver SFX files.

I designed and built the Lua/ReaImGui tool, including overlapping-layer selection, rendered-audio analysis and export checks.

Lua ReaScript · ReaImGui · Windows, macOS and Linux

From selection to files

Select the main item; AutoTrim collects its overlapping layers

It measures the processed result, trims it, applies the chosen level and writes the requested files.

  • Select the sound Choose the timeline item that defines the sound and its initial range.
  • Include its layers AutoTrim adds overlapping items. Long background material is included only when selected.
  • Measure the render A temporary REAPER render captures item and take processing before trimming and level adjustment.
  • Write the files Create one layered file or one file per item, using the chosen name and format.

Analysis uses an uncompressed intermediate render. Final output can be WAV, FLAC, OGG or MP3.

Rendered-audio analysis

AutoTrim measures the processed result, not the source file

Because item and take processing can change the sound, AutoTrim creates an unnormalised intermediate REAPER render before calculating trim points and level adjustment.

Trim & Tails · UI 3.1.3

Find the boundaries without cutting the attack or tail

AutoTrim estimates the local noise level and detects the onset, then uses separate tail detection to preserve reverb and effect decay.

Pre-roll and added tail remain user-controlled, with presets for one-shots, impacts and ambiences. Very long background items are excluded from automatic layer collection unless selected.

Loudness · UI 3.1.3

Measure and adjust level before export

Choose the measurement method, target and true-peak ceiling. AutoTrim validates the measured range and output path before writing the file.

AutoTrim requires REAPER 7 (64-bit) and ReaImGui 0.10.0.5 or newer in the 0.10 API series. SWS is optional.

AutoTrim is proprietary software, and its development repository is private. Public releases support Windows, macOS and Linux.

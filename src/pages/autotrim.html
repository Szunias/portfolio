AutoTrim Exporter

A REAPER tool that turns layered timeline selections into trimmed, named and verified audio assets.

I designed and developed the selection workflow, rendered-signal analysis, level preparation, safe file handling and the interface used to review each delivery.

Lua ReaScript · ReaImGui · Windows, macOS and Linux

Selection to delivery

One timeline selection carries the whole job

AutoTrim removes repeated selection, trimming, naming and render setup while keeping the delivery decisions visible.

  • Anchor Choose one timeline item to define the sound and its initial range.
  • Collect Add its overlapping layers. Long background material stays out unless it was selected deliberately.
  • Prepare Measure the processed signal, set its level and build the delivery name.
  • Deliver Write one layered asset or one file per item, then verify the result.

Analysis stays lossless until delivery. Output can be WAV, FLAC, OGG or MP3.

Signal preparation

The rendered sound sets its own boundaries and level

Item and take processing affect the result, so AutoTrim measures an unnormalised REAPER render instead of inferring the cut from the untouched source file.

Trim & Tails · UI 3.1.2

Trim without cutting the attack or tail

A peak floor, local noise estimate and onset energy locate the start. A separate threshold, hysteresis and a decay-aware window preserve reverb and effect tails.

Pre-roll and extra tail remain explicit, with presets for one-shots, impacts and ambiences. Material far longer than the intended sound set is excluded from automatic batch collection.

Loudness · UI 3.1.2

Prepare level before the final render

The measurement method, target and true-peak ceiling stay together. AutoTrim writes the delivery only after the measured range and output path pass validation.

History and verification

The export is checked before it enters delivery history

History · UI 3.1.2

Analyse. One raw pass establishes the boundaries, with an optional extension pass when the tail needs more room.

Render. The chosen format and level settings are applied once to the measured range.

Commit. AutoTrim checks the file, records diagnostics and either creates a new version or deliberately replaces the requested delivery.

Public release

REAPER 7 + ReaImGui

The interface captures on this page are labelled 3.1.2. GitHub is the source of truth for the version currently available to download.

The package requires REAPER 7 and ReaImGui 0.10.0.5 or newer in the 0.10 API series. SWS is optional. Windows, macOS and Linux are supported.

The development repository is private and the product uses a proprietary license. The distributed Lua ReaScript necessarily contains the Lua text that REAPER runs.

From selection to delivered files

I designed and built the Lua and ReaImGui application and its render workflow.

  1. I select the item that defines the event.
  2. Select across tracks adds the overlapping layers and leaves unrelated long items out unless I select them.
  3. Mandatory Preflight runs before the delivery render.
  4. Profiles, naming and version rules write the files, the history and a batch report.

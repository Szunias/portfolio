AutoTrim Exporter version 3.4.4

I designed and built AutoTrim Exporter, a REAPER tool for delivering sound effects. It gathers a sound’s layers from several tracks, trims the silence around them without cutting the attack or the tail, and verifies every render before the named file reaches the delivery folder.

Designer and developer · Lua ReaScript · ReaImGui · REAPER 7.37+ · Windows, macOS and Linux

Prepare

Export 1

Sound effects rarely sit on one track. An impact, its debris and a sub layer can be three items on three tracks, with a long ambience running underneath. I built Export around the item that anchors the sound: Select overlapping collects the items on other tracks that overlap it, leaves the long unrelated item out and frames the result in the arrange view. Nothing on the timeline moves.

Trim & fades 2

Adaptive silence finds the start and the tail separately, each against its own threshold, then widens both by a pre-roll and a safety ending so the attack and the decay stay whole. The analysis runs on an unnormalised, uncompressed intermediate render. A third pass adds a second analysis render that may scan up to 30 seconds while a long tail is still ringing. Per-item files render through a time-selection window, so the items themselves are never moved or resized.

Loudness 3

A delivery is levelled by one measurement: LUFS-I, RMS, Peak or True Peak, with a true-peak ceiling. Keep original never changes the render gain. Whichever mode is chosen, Peak, RMS and LUFS-I are measured after export and stored with every verified delivery.

Deliver

Format & metadata 4

A delivery profile keeps format, loudness rules, destination, naming and metadata together, so the next batch leaves the same way. The Game / Wwise profile renders 48 kHz, 24‑bit WAV and leaves the level untouched, because in a game the middleware owns the final level. Files can also go out as FLAC, OGG or MP3 while the analysis stays lossless. Names can follow UCS 8.2.1, and each batch can get a delivery report with a verdict for every file.

History 5

History lists every verified file with its path, duration and the Peak, RMS and LUFS-I values the installation can measure, and each row can play, locate or copy its file. Loudness values need the optional SWS extension. A new‑version delivery refuses a name collision that appears at the last moment and never silently replaces project source media; with backups on, Undo restores a replaced file.

The capture is a demo project with synthetic audio and fictional file names.

Check

Preflight 6

Preflight is mandatory and runs before every export. It states what the render will and will not pass through in the current mode: a blocker is a setting that would make the delivered file wrong, and it stops the render, while a second list names where the render will differ from what you monitor. A per-item render, for example, takes the media items directly and skips track, folder and master processing.

In development

Named queues and auditioning

These features are in the development source, not in v3.4.4, and still need manual testing in REAPER. They are for revising a set of sounds: exporting again only what changed, then listening to the result in the same session.

Queue saved with the project
Separated selected clips become groups, each with its own delivery name, and the queue is saved into the REAPER project and loaded from it on request. A new export can include only the groups that changed, without renumbering the rest. Changed layers update from the current selection, and a saved item that has gone missing is reported, never silently substituted.
Auditioning in Media Explorer
After an export, the folder opens in REAPER’s Media Explorer with its volume and loop controls, or in the system file browser; the After export setting chooses. A failed or partial batch keeps its diagnostics on screen.
Game SFX review
An optional, collapsed review reads the delivered files’ measurements and flags headroom and low-level concerns. It does not change audio, fail a delivery or hold every effect to one LUFS target, and a missing measurement shows as unavailable.

The public release

v3.4.4 is a correctness release on top of 3.4.3, the audited release of the 3.4 feature set. In both, an export stays bound to the REAPER project tab it started from, and a failed or interrupted export cannot silently alter another project, overwrite source media or lose its Undo journal. 3.4.4 also adds what the interface lacked: tooltips, an F1 help with the keyboard shortcuts, a Restore defaults command and click targets of at least 32 px.

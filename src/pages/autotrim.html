From selection to delivered files

A sound effect can span several tracks. AutoTrim collects those layers and prepares the export without rearranging the timeline.

  1. Select the item that defines the sound.
  2. Use Select across tracks to include overlapping layers while leaving unrelated long items out.
  3. Choose the delivery profile and review the Preflight checks.
  4. Render the files, with naming, versioning and a report for the batch.

The public v3.4.4 release adds tooltips, F1 help and clearer dependency and Preflight messages. It also corrects render-setting and filename-preview checks.

Named queues and auditioning exports

These additions are implemented in the development source, but are not included in the public v3.4.4 package. Manual REAPER checks are still required before release.

The focus is revising a set of sounds without rebuilding its export queue, then checking the delivered files in the same session.

Keep a queue with the project

Build groups from separated selected clips, give groups their own delivery names, and explicitly save or load the queue in the REAPER project. Include only the groups that need another export without renumbering the rest. Changed layers can be updated from the current selection; missing saved items are reported rather than silently substituted.

Browse deliveries in Media Explorer

Open the export folder in REAPER Media Explorer to audition files with its volume and loop controls, or use the system folder. One After export setting chooses the hand-off; failed or partial batches keep their diagnostics in view.

Review short effects without a blanket loudness target

An optional, collapsed Game SFX review uses delivered-file measurements to flag headroom and low-level concerns. It does not change audio, fail a delivery or assign the same LUFS target to every effect. Unavailable measurements stay explicit.

Delivery history and regression checks

History records each file’s path, duration and available Peak, RMS and LUFS-I measurements. Files can be played, located or copied from the list. Loudness measurement requires the optional SWS extension.

Project isolation
An export stays bound to the REAPER project tab it started from, including while restoring temporary render settings.
Files and Undo
New-version delivery refuses last-moment collisions and never silently replaces project source media. With backups on, Undo restores a replaced file.

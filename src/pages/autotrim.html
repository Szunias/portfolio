AutoTrim Exporter

A REAPER tool that turns layered timeline selections into clean, consistently named audio files.

I am the solo designer and developer. I built the selection workflow, rendered-signal trimming, level preparation, safe file handling and the interface used to review each delivery.

Lua ReaScript · ReaImGui · Windows, macOS and Linux

01

Workflow

One selection becomes a verified delivery

AutoTrim removes repeated selection, trimming, naming and render setup while leaving the delivery decisions visible.

  1. 01AnchorSelect one timeline item.
  2. 02CollectFind the overlapping layers that belong to it.
  3. 03PrepareTrim the render, set its level and build the name.
  4. 04DeliverWrite the chosen format and verify the resulting file.

Select across tracks starts from one timeline item and collects the layers that belong to the same sound. Long background material stays out unless the user selected it deliberately.

The same selection can become one layered asset or one file per item. Delivery formats are WAV, FLAC, OGG and MP3, while the analysis path stays lossless.

02

Boundaries

The processed render decides where the sound begins and ends

AutoTrim measures an unnormalised REAPER render, so item and take processing affect the detected boundaries. It does not infer them from the untouched source file.

Trim & Tails / 3.1.2 capture / presets, thresholds, pre-roll and extra tail
Start
A hard peak floor, local noise estimate and onset energy locate material without shaving off the attack.
Tail
A separate threshold, hysteresis and a decay-aware window preserve reverb and effect tails.
Padding
Pre-roll and extra tail remain explicit controls, with presets for one-shots, impacts and ambiences.
Protection
Material far longer than the intended sound set is excluded from automatic batch collection.
03

Level

Loudness is prepared before the final render

The level view keeps the measurement method, target and true-peak ceiling together. The final delivery is written only after the measured range and output path pass validation.

Loudness / 3.1.2 capture / measurement choices, quick targets and true-peak control
04

Delivery

A file is checked before it becomes a delivery

  1. 01

    Analyse. One raw pass establishes the boundaries, with one optional extension pass when the tail needs more room.

  2. 02

    Render. The chosen format and level settings are applied once to the measured range.

  3. 03

    Commit. AutoTrim checks the file, records diagnostics and either creates a new version or replaces the requested delivery deliberately.

Public release

REAPER 7 + ReaImGui

The interface captures on this page are labelled 3.1.2. The GitHub release page is the source of truth for the version currently available to download.

The package requires REAPER 7 and ReaImGui 0.10.0.5 or newer in the 0.10 API series. SWS is optional. The public package supports Windows, macOS and Linux.

The development repository is private and the product uses a proprietary license. Because it is a Lua ReaScript, the distributed package necessarily contains the Lua text that REAPER runs.

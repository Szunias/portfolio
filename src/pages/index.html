Tools & research

  • AutoTrim Exporter

    A REAPER tool I built for delivering sound effects. It gathers a sound’s layers from several tracks, trims the silence without cutting the attack or the tail, and verifies every render before the named file reaches the delivery folder.

    2026 · Lua ReaScript · ReaImGui View the workflow →

  • AudioQ

    A C++/JUCE sampler: loop a recording, cut it into grains, crush and stutter it.

    v1.0.0 · C++17 · JUCE 8 · VST3

  • MówikF8

    Push-to-talk dictation for Windows: hold F8, speak, release. Transcription runs on the PC.

    2026 · Python · faster-whisper

  • AI Audio Research

    An Unreal client and Python server that measure how late AI-generated sounds arrive.

    2025–2026 · UE 5.4 · C++ · Python

Mówik

mówić is Polish for “to speak”

Mówik is push-to-talk dictation for Windows: hold F8, speak, release, and the text appears where you were typing. Speech recognition is faster-whisper; I wrote the app around it in Python: the microphone buffer, the sound cues, voice commands on a second key and a settings app in Polish and English.

From key press to pasted text

Mówik keeps the microphone open while it runs, holding the last 300 ms of audio in RAM. That buffer becomes the start of every recording and 120 ms are added after release, so the first and last syllables survive a key pressed late or let go early.

On release, faster-whisper transcribes the take on the same computer: on an NVIDIA GPU in float16, or on the processor in int8 when CUDA cannot start. Three quality profiles trade speed for accuracy, from small to large-v3; the default is the low-latency large-v3-turbo.

The text is pasted into the active window, copied to the clipboard, or both. The audio never leaves RAM and is dropped after transcription, and the log never records what was said. A private vocabulary gives the model names and specialist terms. An optional local Ollama model can tidy the punctuation afterwards; if its version changes a number or a negation, or rewrites too much, Mówik keeps the original.

Four sound cues, synthesised in Python

The sound cues are on by default, and they are not audio files: Mówik synthesises them in Python, every note a sine wave with a quiet second harmonic, an 8 ms fade-in and a 32 ms fade-out so that none of them clicks.

Pressing the key plays C5 and releasing it plays G4, a fourth lower. Delivered text answers with a rising major third, C5 to E5, and an error with a falling minor third, E4 to C♯4. Any cue can be replaced with a custom WAV file.

Commands on F7

F7 is a second push-to-talk key for commands. It only reacts to phrases saved in Mówik Center, matched word for word with no fuzzy guessing: anything else does nothing and is never typed out as dictation. Each phrase runs one of three actions.

Insert text
Pastes a saved block exactly as written. A block of several lines asks for confirmation first, because pasted into a terminal it could run.
Open an app, file or website
Existing local paths and HTTPS addresses only, always after a confirmation. Scripts, shortcuts and network paths are blocked.
Open a terminal
Opens in the folder of the active File Explorer window. Words spoken after the phrase can become a one-line draft: Mówik checks it and copies it to the clipboard, and never types it into the terminal or presses Enter.

Installer and releases

The installer needs no administrator rights. The speech model downloads on first launch, and transcription works offline after that. The CUDA libraries weigh close to a gigabyte and only help on NVIDIA cards, so I left them out of the installer: Mówik downloads them the first time a model starts on the GPU and checks them against checksums pinned in the release.

Every release is built by a GitHub Actions workflow from pinned, hash-checked dependencies, then installed in English and in Polish on a fresh Windows image, repaired, launched and uninstalled. Upgrades from older versions and the Windows 10 1809 minimum still need a manual run in a virtual machine before release, and hosted CI has no microphone.

The installer is not code-signed, so Windows may show Unknown publisher or a SmartScreen warning. Each release carries SHA-256 checksums and a provenance attestation, and two PowerShell commands check the file before it runs.

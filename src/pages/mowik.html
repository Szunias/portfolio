Mówik

Push-to-talk dictation for Windows that I wrote in Python around faster-whisper.

Hold F8, speak, release, and the text appears where you were typing.

2026. Python and faster-whisper, Windows 10/11 x64, MIT licence. Settings app in Polish and English. The name comes from mówić, Polish for “to speak”.

From key press to pasted text

Mówik keeps the microphone open and holds the last 300 ms of audio in RAM. That buffer starts every recording, and 120 ms are added after release.

The first and last syllables survive a key pressed late or let go early.

faster-whisper transcribes the take on the same computer: on an NVIDIA GPU in float16, or on the processor in int8 when CUDA cannot start. Three quality profiles run from small to large-v3; the default, Recommended, uses large-v3-turbo.

The text is pasted into the active window, copied to the clipboard, or both. The audio is dropped after transcription and the log never records what was said. A private vocabulary gives the model names and specialist terms, and an optional local Ollama model can tidy the punctuation. If the tidied text changes a number or a negation, or rewrites too much, Mówik keeps the original.

Four sound cues, synthesised in Python

The cues are not audio files. Every note is a sine wave with a quiet second harmonic, an 8 ms fade-in and a 32 ms fade-out, so none of them clicks.

Pressing the key plays C5 and releasing it plays G4, a fourth lower. Delivered text answers with a rising major third, C5 to E5, and an error with a falling minor third, E4 to C♯4. Any cue can be replaced with a WAV file.

Commands on F7

F7 is a second push-to-talk key. It reacts only to phrases saved in Mówik Center, matched word for word with no fuzzy guessing.

Anything else does nothing and is never typed out as dictation.

Insert text
Pastes a saved block exactly as written. A block of several lines asks first, because pasted into a terminal it could run.
Open an app, file or website
Existing local paths and HTTPS addresses only, always after a confirmation. Scripts, shortcuts and network paths are blocked.
Open a terminal
Opens in the folder of the active File Explorer window. Words spoken after the phrase can become a one-line draft, which Mówik checks and copies to the clipboard. It never types it into the terminal or presses Enter.

Installer and releases

The installer needs no administrator rights. The speech model downloads on first launch, and transcription works offline after that. The CUDA libraries weigh close to a gigabyte and only help on NVIDIA cards, so I left them out: Mówik downloads them the first time a model starts on the GPU and checks them against checksums pinned in the release.

A GitHub Actions workflow builds every release from pinned, hash-checked dependencies, then installs it in English and in Polish on a fresh Windows image, repairs, launches and uninstalls it. Upgrades from older versions and the Windows 10 1809 minimum still need a manual run in a virtual machine, and hosted CI has no microphone.

The installer is not code-signed, so Windows may show Unknown publisher or a SmartScreen warning. Each release carries SHA-256 checksums and a provenance attestation, and two PowerShell commands check the file before it runs.

Mówik

I built Mówik, a Windows dictation app that turns speech into text in the active window. I wrote the Python application, local transcription pipeline and Polish and English interface.

Dictating with F8

Hold F8 to record, then release it to transcribe. A short audio buffer helps retain the first syllable. The result goes into the active window, the clipboard or both; the shortcut can be changed in Settings.

Screenshots from the v2.7.4 working build. Current installers and release notes are on GitHub.

Local transcription and audio handling

Mówik does not upload audio or dictated text. Recognition runs through faster-whisper on the computer, not a remote speech service.

Audio
Kept in RAM, discarded after transcription and not saved to disk.
Transcript
Typed or copied on request. Technical logs omit the dictated text.
Model
Downloaded once over the internet. Recognition then uses NVIDIA CUDA in float16 when available, and CPU int8 when CUDA cannot start.
Correction
Off by default. When it is enabled, Ollama runs locally.

Voice commands on a separate shortcut

F7 activates command mode. Configured phrases can insert saved text, open a target or prepare a terminal command.

  • Insert text: types a predefined phrase into the active window.
  • Open a trusted target: a configured app, file or HTTPS address, after confirmation.
  • Copy a terminal command: validated text goes to the clipboard. Mówik does not run it or press Enter.

Installing on Windows

The installer supports 64-bit Windows 10 version 1809 or newer and Windows 11. The speech model downloads on first launch; transcription works offline once it is available.

The installer is unsigned, so Windows may show Unknown publisher or SmartScreen. Each GitHub release includes installation notes, checksums and build verification details.

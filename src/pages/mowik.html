Mówik

mówić is Polish for “to speak”

Mówik is push-to-talk dictation for Windows: hold F8, speak, release, and the text appears in the window you were typing in. I wrote it in Python: the local faster-whisper pipeline, a second key for voice commands and the settings app in Polish and English.

From key press to pasted text

Mówik keeps the microphone open while it runs, holding the last 300 ms of audio in RAM. That buffer becomes the start of every recording and 120 ms are added after release, so the first and last syllables survive a key pressed late or let go early.

On release, faster-whisper transcribes the recording on the same computer: on an NVIDIA GPU with CUDA in float16, or on the processor in int8 when CUDA cannot start. The quality profile picks the model.

The text is pasted into the active window, copied to the clipboard, or both. The audio never leaves RAM and is dropped after transcription, and the technical log never contains what was said. A private vocabulary passes names and specialist terms to the model as a prompt; correction through a local Ollama model is available and off by default.

Commands on F7

F7 is a second push-to-talk key for commands. It only reacts to phrases saved in Mówik Center, matched word for word with no fuzzy guessing: anything else does nothing and is never typed out as dictation. Each phrase runs one of three actions.

Insert text
Pastes a saved block exactly as written. A block of several lines asks for confirmation first, because pasted into a terminal it could run.
Open an app, file or website
Existing local paths and HTTPS addresses only, always after a confirmation. Scripts, shortcuts and network paths are blocked.
Open a terminal
Starts in the folder of the active File Explorer window, a fixed folder or the home folder. Words spoken after the phrase can become a one-line draft: Mówik checks it and copies it to the clipboard, and never types it into the terminal or presses Enter.

All three are blocked while Mówik runs with administrator rights, so its simulated keystrokes and the programs it starts cannot cross an elevation boundary.

Installing on Windows

The installer runs on 64-bit Windows 10 version 1809 or newer and on Windows 11, without administrator rights. The speech model downloads on first launch, and transcription works offline after that. The CUDA libraries weigh close to a gigabyte and only help on NVIDIA cards, so I left them out of the installer: Mówik downloads them the first time a model starts on the GPU and checks them against checksums pinned in the release.

Official builds come from a GitHub Actions workflow in the repository, which attaches a provenance attestation. The installer is not code-signed, so Windows may show Unknown publisher or a SmartScreen warning. Two PowerShell commands check the downloaded file before it runs.

Mówik

Mówik is a Windows push-to-talk dictation app that inserts transcribed speech into the active window.

I wrote the Python app and its transcription pipeline, and I maintain the Polish and English interface and the Windows releases.

Push-to-talk dictation

Push-to-talk transcription and output

F8 is the default shortcut, but it can be changed in Settings.

  1. Hold F8A short RAM pre-roll helps retain the first syllable.
  2. SpeakThe recording stays in memory while the shortcut is held.
  3. Releasefaster-whisper transcribes the recording locally.
  4. ContinueThe text is typed, copied to the clipboard or both.

Optional sound cues mark the start of recording and the end of transcription.

Local processing

Mówik does not upload audio or dictated text

Speech recognition runs through faster-whisper on the computer instead of a remote speech service.

Audio
It is kept temporarily in RAM, discarded after transcription and not saved to disk.
Transcript
It is typed or copied, while technical logs omit the dictated text.
Model
Internet is needed once to download it. Recognition then uses NVIDIA CUDA in float16 when available and automatically falls back to CPU int8 if CUDA cannot start.
Optional correction
Ollama support is off by default and uses a locally running instance when enabled.

Custom commands · Since v2.7

Voice commands insert text, open targets or copy terminal commands

F7 is the default shortcut. Each custom voice command pairs an exact spoken phrase with a preset action.

  • Insert text. Types a predefined phrase in the active window.
  • Open a trusted target. Opens a configured app, file or HTTPS address after confirmation.
  • Copy a terminal command. Copies validated text to the clipboard. Mówik does not execute it or press Enter.

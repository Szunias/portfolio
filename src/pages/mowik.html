Push-to-talk dictation

A shortcut turns speech into text without interrupting the current task

F8 is the default shortcut. Releasing it starts recognition; the finished text goes to the active field, the clipboard or both.

  1. Hold F8The open microphone keeps a short pre-roll in RAM.
  2. SpeakAudio stays in memory while the shortcut is held.
  3. ReleaseLocal faster-whisper recognises the recording.
  4. ContinueText reaches the active field, clipboard or both.

The pre-roll catches the first syllable. Mówik discards the audio after transcription and does not save it to disk.

The first model download needs internet. Recognition then uses NVIDIA CUDA in float16 when supported and falls back to CPU int8 automatically.

Interface and local boundary

Daily controls stay close; model details remain out of the way

The main settings expose the shortcut, microphone, language, quality profile and feedback. Model, device, speech detection and buffer controls remain under Advanced.

Recognition boundary

Mówik does not upload audio or dictated text

Recognition does not send recordings or dictated text to a remote speech service.

Audio
A short buffer lives in RAM and is never written to disk by Mówik.
Transcript
It is typed or copied, while technical logs omit the dictated text.
Model
The selected model is downloaded first, then faster-whisper runs it locally.
Optional correction
Local Ollama support is off by default and connects only to 127.0.0.1.

Custom commands · Since v2.7

Terminal commands stop at the clipboard

F7 is the default command shortcut. Commands require an exact phrase, and anything intended for a terminal is left as a draft for the user to review.

  • Insert text. A command can place a predefined phrase in the active window.
  • Open a trusted target. An app, file or HTTPS address requires confirmation.
  • Draft a terminal command. The validated text is copied to the clipboard. Mówik does not execute it or press Enter.

Three Wwise exercises

I did the audio implementation in Wwise for three Unity exercises: which sounds keep playing when skeletons crowd the screen, how a walk from a forest into a cave sounds, and how an Android build loads each area’s sounds only when it needs them.

Boney Boogaloo Playback priority

In the test scene, skeletons in suits keep rising over the hill, and more sounds play at once than the project’s voice limit allows. I set the playback priorities that decide what you still hear: nearby weapons keep playing and distant enemy voices drop out first.

Ellen Forest to cave

When the player walks from the forest into the cave, the two ambiences crossfade and the reverb changes with them instead of switching in one step. I also set the attenuation for each type of sound, which decides how quickly it fades with distance.

Stomach Aches Memory on Android

The Android build of Stomach Aches had to fit low-memory phones, so I grouped its sounds by area and the game loads only what it currently needs. I also replaced the audio files that only held silence with the Wwise Silence plug-in, so the gaps no longer cost memory.

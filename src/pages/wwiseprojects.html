Three Wwise implementation studies

Three solo DAE exercises: voice prioritisation in a zombie shooter, spatial transitions in a platformer and zone-based audio loading for an Android build.

01 · Voice priority

Boney Boogaloo

The first mix reached Wwise’s 256-voice limit and dropped important gunshots. I trimmed dead air and set priorities so nearby weapons win over distant zombie vocals.

02 · Spatial transition

Ellen

Each sound type uses its own attenuation curve. Forest and cave ambiences crossfade over 6.5 seconds while the reverb changes with the space, avoiding a hard switch at the zone boundary.

03 · Mobile memory

Stomach Aches

The Android build targeted 2 GB devices. Audio is split by zone so only the current area stays loaded; replacing placeholder files with Wwise Silence reduced those placeholder assets by 80%.

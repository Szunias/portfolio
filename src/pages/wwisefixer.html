Wwise UE Fixer

Wwise UE Fixer is a Windows tool for Unreal projects whose audio settings fall out of sync after a Perforce update. I built it in Python to find mismatches, repair three known problems and back up every file it may change.

Solo tool developer · Windows 10/11 · MIT

What it changes

It fixes three settings and only reports the rest

The tool checks the project’s Wwise plug-in entry, audio paths, generated SoundBanks and Perforce settings.

For a supported problem, Quick Fix changes only the one project or configuration file required. It explains other problems but leaves their files untouched.

What Quick Fix can change
CheckActionFile changed
Wwise plug-in entryQuick Fix.uproject
SoundBank pathQuick FixDefaultGame.ini
AkSettings sectionQuick FixDefaultEngine.ini
Other reported issuesDiagnostic onlyNo automatic change

Before a supported repair, the tool copies the .uproject file and the Config directory. It does not back up Content, Source or the full project.

In the Shadow Frames workflow, the automatic step took about ten seconds. Regenerating project files, restarting Unreal and testing the audio still followed.

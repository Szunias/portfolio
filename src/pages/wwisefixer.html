Wwise UE Fixer

A Python diagnostic and repair utility for Wwise integrations in Unreal after Perforce syncs. I built the checks, three scoped configuration repairs and the backup step.

Solo tool developer · Python · Windows 10/11 · MIT

Tool scope

Diagnostics, three repairs and scoped backups

The diagnostic pass checks whether the Wwise plug-in, project paths, generated banks and Perforce settings agree. Issues outside the three supported repairs are reported without changing files.

Before a supported repair, the utility copies the .uproject file and the Config directory. It does not archive Content, Source or the full project. In the Shadow Frames workflow the automated pass took about ten seconds; project-file regeneration, an Unreal restart and an audio test still followed.

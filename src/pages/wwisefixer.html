Wwise UE Fixer

After some Perforce syncs, Shadow Frames opened with broken Wwise configuration and silent audio. This Python utility diagnoses the integration and applies three scoped fixes.

Tool developer · Python · .bat launcher

Diagnostics

What it checks

The tool checks the plugin entry and installation, SoundBank location, AkSettings, Wwise project presence, integration files, path consistency, Perforce configuration, generated banks and plugin-version information.

Most of those checks are diagnostic. They report what is missing or inconsistent without claiming that every detected problem can be repaired automatically.

Quick Fix

The three changes it can apply

.uproject plugin entry

Repairs the supported Wwise plugin entry in the Unreal project file.

SoundBank directory

Corrects the supported SoundBank path in DefaultGame.ini.

AkSettings

Applies the supported AkSettings section in DefaultEngine.ini.

Safety and scope

Copies the files it may change

Before Quick Fix runs, the tool copies the .uproject file and Config directory. It does not archive Content, Source or the full project.

In the Shadow Frames workflow, the automated repair pass took about ten seconds. Regenerating project files, restarting Unreal and testing audio still happened afterwards.

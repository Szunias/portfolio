Wwise UE Fixer

A Python diagnostic and repair utility for Wwise integrations in Unreal after Perforce syncs. I built the checks, three scoped configuration repairs and the backup step.

Solo tool developer · Python · .bat launcher

Tool scope

Diagnostics, three repairs and scoped backups

The diagnostic pass checks the plugin entry and installation, SoundBank location, AkSettings, Wwise project, integration files, path consistency, Perforce configuration, generated banks and plugin-version information. Checks that cannot be repaired automatically remain reports.

Quick Fix can repair the supported Wwise entry in the .uproject file, the SoundBank path in DefaultGame.ini and the AkSettings section in DefaultEngine.ini.

Before making those changes, the utility copies the .uproject file and the Config directory. It does not archive Content, Source or the full project. In the Shadow Frames workflow the automated pass took about ten seconds; project-file regeneration, an Unreal restart and an audio test still followed.

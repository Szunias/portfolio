Three Wwise exercises

2023–2024 · Audio implementation · Wwise · Unity · DAE exercises

Three exercises from DAE, each one a common game-audio problem in Unity.

I did the implementation on all three: keeping important gunshots audible, blending sound between two locations and cutting audio memory use on Android.

Boney Boogaloo: keeping gunshots audible

The test scene played more simultaneous sounds than the project’s voice limit allowed, so important gunshots dropped out. I removed the silent gaps and set playback priorities, so nearby weapons play before distant zombie voices.

Ellen: forest to cave

I set how quickly each type of sound fades with distance. When the player moves between the forest and the cave, the two backgrounds crossfade and the room echo changes with them instead of switching suddenly. A still frame cannot show a transition, so there is a recorded walk between the forest and the cave ↗ that covers the blend and the change in room echo.

Stomach Aches: audio memory on Android

The Android build had to fit low-memory phones. I grouped sounds by area so the game loads only what it currently needs, and replaced the files that existed only to create silent gaps with the Wwise Silence plug-in, so those gaps no longer cost memory.

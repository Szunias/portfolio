Implementation

Sampler, effects and host state

Sample or loop region → granular playback → filters → compressor → tremolo → glitch effects → dry/wet blend.

WAV, AIFF and MP3 files load into a draggable waveform. The player supports a selectable loop region, an optional loop crossfade and manual 20–300 BPM resampling.

JUCE StateVariableTPT low-pass and high-pass filters and a JUCE compressor sit alongside custom tremolo, bitcrusher, stutter and chunk-reverse processors. APVTS stores plugin state and exposes the parameters to a VST3 host.

Overlapping grains can create large peaks. The compressor handles normal peaks; a separate monitor stops playback above 4.0 linear gain. That stop is a last-resort fail-safe, not hearing protection. Verified host, OS, sample-rate and channel-layout coverage is still pending.

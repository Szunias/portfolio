AudioQ

AudioQ is a sampler plug-in. It loads a sound, turns any part of it into a loop and reshapes the playback with granular mode and effects.

Sole developer · public v1.0.0, 9 November 2025 · C++17 · JUCE 8 · MIT

Loading a sound and looping it

AudioQ loads WAV, AIFF and MP3 files. The 20–300 BPM control changes playback speed; it does not time-stretch the file to a detected tempo.

I built it alone in C++ and JUCE. The waveform editor, the playback engine and the DSP chain are all mine.

The recorded demo runs through loading, looping and processing a sound. It uses an earlier interface than the screenshot above.

The order the controls run in

Granular mode changes the source playback before the sound reaches the effects. The three crops are the v1.0.0 window in the order the signal passes through it.

The safety limit

The compressor handles normal peaks. If the signal still exceeds 4.0 linear gain, a separate fail-safe stops playback. It is a last resort, not certified hearing protection.

The live output display, after the whole chain.

What is still untested

I rebuilt the plugin more than once before the public release. The download is a Windows VST3 build. The source also builds a standalone app, but broader testing across hosts, operating systems, sample rates and channel layouts is still pending.

Design round / 10 independent directions

Portfolio directions

These are separate information architectures, not colour variations. Open each direction, judge how quickly you understand the work, then pick the one worth developing.

01Field Notes

A production notebook built from decisions, tests and evidence.

→ 02Cinema Index

Film stills and exact credits in a restrained vertical sequence.

→ 03Technical Manual

Documentation hierarchy for implementation-heavy work.

→ 04Editorial Columns

Dense multi-column reading with projects as reported work.

→ 05Project Room

Select one project and inspect its evidence without leaving the page.

→ 06Compact Reel

Reel, project credits and contact in the shortest useful page.

→ 07Studio Ledger

A chronological record of roles, teams, tools and outcomes.

→ 08Quiet Gallery

Carefully selected project images with concise supporting captions.

→ 09Role First

Capabilities first; projects appear as evidence underneath.

→ 10CV + Evidence

A fixed professional profile paired with a project proof archive.

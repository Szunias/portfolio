# Dark portfolio React concept

An independent React/Vite portfolio concept. It is not used by the live build.

## Design decisions

- The hierarchy starts with project, exact role and concrete contribution.
- Media supports project claims; there are no decorative audio visualisations.
- Project filters reduce the page without hiding the full body of work by default.
- The dark palette uses high-contrast text and a single muted blue accent.
- Layout, labels and navigation stay consistent across projects.

Research references:

- https://wolffsound.com/
- https://www.lathamaudio.com/projects/
- https://www.waltersie.com/portfolio
- https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html

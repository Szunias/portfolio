# Portfolio design experiments

These directories are archived design and implementation experiments. They are
not used by the live static site or by `build.cjs`.

- `dark-portfolio-react/` — an earlier React-based portfolio prototype.
- `portfolio-mockups/` — the first set of visual layout mockups.
- `portfolio-mockups-round2/` — a second set of visual layout mockups.
- `redesign/` — standalone redesign concepts.

Generated dependencies and build output (`node_modules/` and `dist/`) remain
excluded by the repository's root `.gitignore`.

# Design Research Brief: Portfolio Rebuild v2
**Research Date**: 2026-02-23
**Researcher**: design-researcher
**Context**: Game audio student portfolio (Igor Szuniewicz, 22, DAE Belgium)

---

## Executive Summary

Current site feels AI-generated and template-like. Research reveals that **game audio portfolios struggle universally with visual identity** because sound is invisible. Most fall into template traps: centered hero + photo + generic copy. The breakthrough is **treating typography and negative space as the primary visual language** rather than trying to illustrate sound.

Key insight: Igor's youth and student status is an ASSET, not a liability. The tone should be confident but humble, specific but casual. Like a smart peer showing their work, not a senior selling services.

## 2. Home Page Structural Recommendations

### Option A: Type-as-Brand Hero (Recommended)
**Structure**:
```
[Large, bold typography]
IGOR SZUNIEWICZ
Audio Designer for Games

[Smaller, secondary line — humble but specific]
Built sound for 4 games. 200+ Wwise events. Third-year student at DAE.

[Minimal CTA]
[View Work] or [Listen ↓]
```

**Key moves**:
- Name is HUGE — 80-120px, fills the viewport width
- "Audio Designer for Games" — not "game audio designer" (less jargon)
- No photo, no gradient, no centered block — name is offset left or spans asymmetrically
- Teal accent ONLY on one word (e.g., "Audio" or his last name)
- Background: pure dark (#0a0a0a) with subtle noise texture

**Why it works**: Makes his NAME the brand. Typography does the heavy lifting. No photo = no distraction, no AI vibes.

### Option B: Audio-as-Visual Hero
**Structure**:
```
[Subtle animated waveform or frequency bars in background — abstract, not literal]
IGOR SZUNIEWICZ

[Tagline under name]
Sound design for games. Currently breaking 200 Wwise events.

[Showreel embed or audio player prominently placed]
```

**Key moves**:
- Background animation is SUBTLE — grayscale, low opacity, slow
- Waveform is decorative, not data (no need to be real audio)
- Audio player or showreel video is the hero CTA
- Layout is still asymmetric — player offset right, text offset left

**Why it works**: Solves the "audio is invisible" problem. Makes sound feel tangible without photos.

### Option C: Statement + Negative Space
**Structure**:
```
[Top-left or centered, large but not massive]
IGOR SZUNIEWICZ

[Huge amount of whitespace/negative space]

[Bottom-right, small but confident]
Audio designer.
Four games.
One showreel.
[View ↓]
```

**Key moves**:
- Extreme minimalism — almost nothing on screen
- Name is present but not dominating
- Confidence through restraint (not trying too hard)
- Negative space = "I don't need to prove anything, the work speaks"

**Why it works**: Subverts expectations. Feels editorial, not portfolio-template.

## 3. About Page Structural Recommendations

### Option A: Fragmented Narrative (Recommended)
**Structure**:
```
[Short intro — 2 sentences max]
22. Third-year audio student. Worked on 4 games so far.

[Three-column grid — varied heights]
Column 1: Education
- DAE (Digital Arts and Entertainment), Belgium
- Audio specialization
- Graduating 2027

Column 2: Skills (honest)
- Wwise (200+ events implemented)
- Field recording
- Foley
- Sound design
- Learning: procedural audio, music production

Column 3: Currently
- Working on [Project Name]
- Freelancing for indie devs
- Building [specific thing — e.g., "building a footstep system in Unity"]

[Full-width section — personal]
Honest paragraph: what draws him to game audio, what he's still learning, what he wants to build next.
Casual. Fragments OK. No corporate speak.

[Footer — links]
Email / LinkedIn / SoundCloud / GitHub
```

**Key moves**:
- **Varied rhythm** — intro is short, grid breaks it up, personal paragraph at end
- Columns have **unequal heights** — not uniform cards
- "Currently" section is time-sensitive (shows he's active, not static)
- Personal paragraph is REAL — "I'm still figuring out X" or "I want to get better at Y"

**Why it works**: Reads like a conversation. Breaks the bio-template. Feels like a real person, not a resume.

### Option B: Timeline + Skills Interwoven
**Structure**:
```
[Intro — humble]
I'm Igor. I make sound for games.

[Timeline — left-aligned, year markers]
2023: Started DAE
2024: First game shipped (Name)
2024: Learned Wwise, did foley for 3 projects
2025: Freelanced for [Studio], built [specific system]
2026: Currently working on [Project]

[Skills section — NOT a list]
I work in Wwise. I've implemented 200+ events across 4 games. I do field recording and foley.
I'm learning procedural audio and music production. Still figuring out interactive music.

[Links]
```

**Key moves**:
- Timeline is **chronological and specific** — shows progression
- Skills written as **sentences, not bullet points** (more human)
- "Still figuring out" = honest, not corporate
- Layout is linear, not grid-based (unusual for about pages)

**Why it works**: Shows growth. Reads like a story. Doesn't hide that he's a student.

**Why it works**: Unexpected. Reads like a real conversation. Easy to scan.

## 4. Copy Tone Guidelines

### Core Principles
1. **Short sentences. Fragments are fine.**
2. **Specific > vague.** "200+ Wwise events" beats "extensive experience."
3. **Past tense verbs: did, built, fixed, made.** NOT: led, architected, leveraged, optimized.
4. **It's OK to be casual and slightly self-deprecating.** He's a student, not a senior.
5. **No corporate jargon.** If it sounds like a LinkedIn post, rewrite it.

### Good vs. Bad Examples

| Bad (Corporate/AI) | Good (Humble/Specific) |
|-------------------|------------------------|
| "Led audio implementation for 4 titles" | "Did audio for 4 games" |
| "Passionate about immersive soundscapes" | "I like making things sound good" |
| "Leveraged Wwise to optimize audio performance" | "Built 200+ Wwise events. Still learning procedural audio." |
| "Dedicated to crafting memorable audio experiences" | "Made footsteps, explosions, UI sounds. Fixed bugs." |
| "Proficient in field recording and foley" | "I do field recording and foley. Recorded doors, footsteps, broken glass." |

### Sentence Length
- Average: 8-12 words
- Longest: 20 words max
- Fragments: totally fine

### Forbidden Words/Phrases
- Passionate / dedicated / committed
- Led / spearheaded / architected
- Leveraging / optimizing / streamlining
- Extensive experience / proven track record
- Immersive / cutting-edge / innovative
- Solutions / synergy / impact

### Allowed Casual Phrases
- "I'm still figuring out..."
- "Currently learning..."
- "Not great at X yet, but getting there"
- "Built this. Broke it. Fixed it."
- "Did X for Y project. Took Z weeks."

## 5. Visual Direction Suggestions

### Color Palette
**Current issue**: Teal accent on dark bg looks generic (every dark-mode portfolio uses teal/cyan)

**Recommendations**:

**Option A: Warm Accent (Unexpected for Tech/Audio)**
- Base: `#0a0a0a` (near-black)
- Text: `#e8e8e8` (off-white)
- Accent: `#ff6b35` (warm orange-red) or `#f9c74f` (warm yellow)
- Why: Audio is warm (analog, human). Breaks the teal/purple trend.

**Option B: High-Contrast Monochrome + Single Bold Accent**
- Base: `#000000` (true black)
- Text: `#ffffff` (true white)
- Accent: `#00ff00` (bright green, sparingly — like 2-3 uses max)
- Why: Terminal/editor vibes. Technical but not corporate. Green = sound is "on."

**Option C: Muted Earth Tones (Editorial Feel)**
- Base: `#1a1a1a` (charcoal)
- Text: `#d4d4d4` (light gray)
- Accent: `#8b7355` (muted brown/tan) or `#6b8e23` (olive green)
- Why: Feels handcrafted, analog, organic. Less "tech bro," more "audio nerd."

### Typography
**Current issue**: Likely using Inter or Poppins (default Tailwind fonts)

**Recommendations**:

**Option A: Grotesque + Mono**
- Headings: `Space Grotesk` or `Archivo Black` (bold, geometric, slightly industrial)
- Body: `Inter` (clean, readable)
- Accent/code: `JetBrains Mono` (for numbers, tech specs — "200+ events")
- Why: Grotesque feels audio-tech. Mono adds technical credibility.

**Option B: Condensed + Wide**
- Headings: `Bebas Neue` or `Oswald` (condensed, tall, impactful)
- Body: `Work Sans` (wide, modern, friendly)
- Why: Contrast between narrow headings and wide body creates rhythm.

**Option C: Serif + Sans (Editorial)**
- Headings: `Playfair Display` or `Lora` (serif, editorial, confident)
- Body: `Inter` or `Source Sans Pro`
- Why: Unexpected for a game audio site. Feels editorial, magazine-like.

### Motion Approach
**Current issue**: Likely using generic fade-in/slide-up (Framer Motion defaults)

**Recommendations**:

**1. Audio-Reactive Micro-Interactions**
- Buttons pulse subtly on hover (like a VU meter)
- Scroll progress bar styled like a waveform
- Page transitions feel like "scrubbing" audio (fast, directional)

**2. Asymmetric Stagger**
- Instead of all cards fading in at once, stagger them unevenly (0.1s, 0.3s, 0.2s — not uniform)
- Elements enter from different directions (not all from bottom)

**3. Minimal Motion**
- Only animate on interaction (click, hover) — no auto-play animations
- Scroll-driven reveals (appear as you scroll past, not on page load)
- Feels intentional, not decorative

**4. Sound-Inspired Easing**
- Use `ease-out` curves that mimic audio envelopes (fast attack, slow decay)
- Custom bezier: `cubic-bezier(0.16, 1, 0.3, 1)` — snappy but smooth

### Dark Mode Specifics
- **Avoid pure black** (`#000`) unless going for high-contrast monochrome
- Use `#0a0a0a` or `#121212` (softer on eyes)
- Text should be `#e8e8e8` or `#d4d4d4` (NOT pure white — reduces eye strain)
- Shadows: use colored shadows (e.g., `box-shadow: 0 4px 20px rgba(255, 107, 53, 0.15)` for orange accent)

## 6. Anti-Patterns to AVOID (Critical)

### Layout Anti-Patterns
❌ Centered text block + gradient background
❌ Photo + text two-column hero
❌ Every section follows same structure (heading → description → content grid)
❌ Uniform card grids with equal spacing
❌ Skills section with progress bars
❌ "Hi, I'm [Name]" hero text

### Copy Anti-Patterns
❌ "Hi, I'm Igor. I'm a passionate game audio designer..."
❌ "I specialize in creating immersive soundscapes..."
❌ "With extensive experience in Wwise and FMOD..."
❌ Paragraphs longer than 4 lines
❌ Bullet points that start with "Led," "Managed," "Optimized"

### Visual Anti-Patterns
❌ Teal/cyan accent on dark background (overdone)
❌ Generic gradient overlays
❌ Auto-playing background video
❌ Particle effects / floating shapes
❌ Generic geometric patterns
❌ "Glowing" neon effects

### Tone Anti-Patterns
❌ Corporate LinkedIn language
❌ Over-selling credentials ("award-winning," "industry-leading")
❌ Vague claims without specifics
❌ Third-person bio ("Igor is a game audio designer...")
❌ Excessive modesty ("just a student, still learning everything")

## 7. Implementation Notes for Architects

### React + Tailwind + Framer Motion Constraints
- **Keep components reusable but NOT over-abstracted** (per MEMORY.md: avoid premature abstraction)
- **Use Tailwind utilities** for layout — avoid custom CSS unless necessary for unique effects
- **Framer Motion**: Use `motion.div` with viewport-based animations (`whileInView`), not page-load animations
- **i18n**: All text must be in `home.json` and `about.json` namespaces (EN/PL/NL) — NO hardcoded English
- **Dark mode only** — no light mode toggle needed

### Accessibility Checks
- Typography-heavy design needs **high contrast ratios** (WCAG AA minimum: 4.5:1 for body, 3:1 for headings)
- If using animated waveforms, **provide reduced-motion alternative** (`prefers-reduced-motion: reduce`)
- Ensure all interactive elements are **keyboard-navigable** (tab order, focus states)
- Audio players need **visible labels and controls**

### Performance
- Async/lazy-load any audio visualizations (don't block page render)
- Use `loading="lazy"` for project images (if any)
- Framer Motion animations should use `transform` and `opacity` (GPU-accelerated), not `width`/`height`

## Conclusion

The key to making Igor's portfolio feel **real and not AI-generated** is:

1. **Typography as primary visual** (no photo needed)
2. **Asymmetric, editorial layout** (not uniform sections)
3. **Humble, specific copy** (not corporate jargon)
4. **Intentional restraint** (less is more)
5. **Audio-inspired motion** (not generic fades)

The architects should **start with Home hero redesign** (Option A: Type-as-Brand recommended) and **About page restructure** (Option A: Fragmented Narrative recommended). Copy tone is CRITICAL — every sentence should pass the "would a 22-year-old student actually say this?" test.

The Projects

Three different problems that made me learn how audio middleware actually works under the hood.

Boney Boogaloo

Wwise v2021 Windows 2 weeks

Boney Boogaloo - Gameplay

Every gunshot sounds different. 30+ zombies on screen and you can still hear spawns clearly.

Zombie wave shooter. Up to 5 zombies on screen at once. My first Wwise project.

Hit the 256-voice limit fast - player firing constantly plus zombie spawns. Set up random containers with 6 gunshot variations and 6 spawn sounds so nothing sounds repetitive.

Did volume balancing in Wwise (-2dB on shots, +4dB on player hurt, -5dB on zombies). Trimmed silence from files. Used ADPCM compression.

44 sounds total across 9 random containers. Simple routing to Master Bus, no effects, 2D audio only.

Ellen

Wwise v2021 Windows 3 weeks

Ellen - Gameplay

Full Wwise implementation with spatial audio, dynamic mix, and Game Syncs integration.

Platformer with magic combat. First time doing spatial audio.

Built 10 attenuation curves - enemies at 25m, footsteps at 75m, explosions at 100m. Material switching on footsteps through raycasts checking surface types.

Adaptive ambience with State groups - different zones crossfade ambient layers over 6.5 seconds. Set up 4 reverb buses for different room sizes.

Compression strategy: Music Q8 OGG, Ambience Q7, SFX Q5, voice ADPCM.

Stomach Aches

Wwise 2024 4 Platforms 3 weeks

Stomach Aches - Gameplay

Waterfall layers blend as you approach. Footsteps auto-switch between different body materials.

FPS platformer inside a human body. Three zones - Brain, Mouth, Stomach. Had to run on Android with 2GB RAM.

15MB audio limit on cheap Android. Implemented zone-based soundbank loading - only load audio for the zone you're in. Brain 670KB, Mouth 384KB, Stomach 2.8MB.

Used Wwise Silence plugin instead of silent files (80% memory saved). Waterfall system with RTPC - 3 layers crossfade based on distance: Close 130KB, Mid 6.3MB, Far 3.6MB.

Material switching for footsteps. Music streams to save RAM. Proper loop cleanup to prevent orphaned sounds.

What I Learned

Skills from fixing problems when they broke

Working within sound channel limits, tracking memory budgets, picking compression that balances file size vs quality.

3D Audio

Writing distance curves for different sound types, positioning audio in 3D space, making sounds fade at the right ranges.

Middleware Integration

Connecting game events to middleware, making audio respond to player position and game state without hardcoding values.

Memory Management

Deciding what loads immediately, what streams from disk, what unloads when changing zones. Staying under budget on phones.

Unity + Wwise

Writing C# scripts that talk to Wwise API, handling zone triggers, cleaning up sounds that don't stop properly.

Multi-Platform

Different compression strategies for PC vs mobile. Testing on emulators. Profiling memory to catch issues before shipping.

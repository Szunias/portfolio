Boney Boogaloo

Wwise v2021.1.14 Windows

A zombie shooter where waves of enemies spawn constantly. The challenge was keeping the audio working when 50+ zombies are on screen at once, all making noise.

The Problem

Voice Limit Crisis

Too many sounds playing at once causes audio engine to cut off important sounds

Repetitive Audio

Same gunshot playing 100 times sounds robotic and boring

What I Did

Voice Budget Management

Set 256 voice global limit with virtualization - quiet sounds pause instead of stopping

Random Containers

10 containers with 44 assets - each gunshot/zombie sound picks randomly from pool

Manual Optimization

Hand-trimmed silence from every file, custom loop regions for ambience

Random Containers Voice Virtualization ADPCM Compression

Ellen

Wwise v2021.1.14 Windows

Third-person action game with different zones - jungle, caves, buildings. Audio needed to adapt smoothly when you move between areas, and enemies needed to sound right at different distances.

The Problem

Zone Transitions

Audio cutting abruptly when entering buildings felt jarring and unpolished

Spatial Audio

Enemy footsteps need different ranges - close threats vs distant awareness

What I Did

State-Driven Ambience

6.5s crossfades between jungle/cave/building - Wwise handles it automatically

Custom Attenuation

10 curves ranging 11m (debris) to 155m (gates) - each sound has purpose

RTPC Reverb Control

4 AUX buses controlled by game parameters - designers can tweak in-editor

State System RTPC 3D Positioning Material Footsteps

Stomach Aches

Wwise 2024.1.2 Multi-platform

FPS platformer set inside a human body. This one needed to run on everything from Windows to low-end Android phones with 2GB RAM. Memory was the main enemy here.

The Problem

RAM Budget

Android_Low devices can't hold all audio in memory - needed 10-15 MB max

Platform Differences

Windows can handle uncompressed audio, Android needs aggressive optimization

What I Did

Zone-Based Loading

Soundbanks swap as you move (Brain → Mouth → Stomach), saving 3.8 MB RAM

Silence Plugin Trick

Procedural silence for gaps instead of WAV files - 80% memory reduction

C# Integration

WwiseStateBridge, WaterfallDistanceRTPC - custom scripts for dynamic audio

What I Learned

Technical skills I picked up from working on these projects

Managing memory budgets, setting voice limits, choosing compression that balances quality vs size.

🔊 Spatial Audio

3D positioning, attenuation curves, cone settings - making sounds work in 3D space.

⚙️ Game Syncs

States for zones, switches for materials, RTPCs for dynamic mixing - connecting game to audio.

📦 Soundbank Strategy

🔗 Unity Integration

📱 Multi-Platform

Project 01 · Windows

Boney Boogaloo

Zombie shooter implemented in Wwise v2021.1.14 Build 8108 to prove out random container workflows, voice management, and manual optimization on a 44-asset library.

Random Containers Voice management Manual editing
Evidence: JSON

Snapshot

Wwise build
v2021.1.14 Build 8108 · Target platform: Windows
Scope
10 containers (9 Random + 1 Sequence) covering 44 sound assets
Voice budget
Global cap 256 · Queue virtualization · -80 dB culling · Ambience limited to 1
Toolkit
Random container library, SC_Round_Progress, ADPCM/PCM conversion, trim + fade editing

Impact

  • Variation ready. Random Containers cover guns, zombie spawns, gore hits, player hurt VO, and knife stabs, so one Unity event automatically cycles six shots, six spawns, three gore layers, and four hurt lines.
  • Voice ceiling protected. Global 256 cap, Queue virtualization, -80 dB culling, and a single ambience instance keep enemy rushes within budget.
  • Seamless ambience. Forest loop runs on a custom 30.87s–102.41s region with 1.4s fade-in / 1.8s fade-out, so the background never pops or stutters.
  • Hand-trimmed assets. Reloads trimmed 0.495 s, cock 0.192 s, announcer VO 1.1–1.2 s, and ammo loads 0.19–0.21 s to remove silence without touching fidelity.

Systems delivered

  • Random container network for weapons, zombies, gore, player hurt, and stealth reveals with volume offsets (-2 dB to -7 dB) baked in.
  • SC_Round_Progress sequence container guarantees Round 1 → 4 announcer order after trims and level matching.
  • Ambience bus capped at one instance plus custom loop points, fades, and ADPCM/PCM conversion keep CPU and RAM predictable.

Project 02 · Windows

Ellen

Third-person action vertical slice focused on state-driven ambience, RTPC-based reverb, and content-aware compression in Wwise v2021.1.14 (Windows reference platform).

State-driven ambience RTPC reverb Targeted compression
Evidence: JSON

Snapshot

State system
MusicZone state group controls SC_AMB with 6.5s crossfades for Jungle, Main Chamber, and Building zones.
Attenuation coverage
10 custom curves (11 m box debris → 155 m gate) for footsteps, grenades, gates, and UI cues.
Reverb network
4 AUX buses (Cave, StoreRoom, Stone Big, Stone Small) driven by Reverb_* RTPCs via AkRTPCManager.
Compression plan
Music Vorbis Q8, Ambience Q7, SFX Vorbis Q5 @ 44.1 kHz, VO ADPCM, UI Vorbis Low with streaming enabled for large loops.

Impact

  • Frictionless zone transitions. ContinuousPlayback + 6.5 s fades mean entering a building only sets a state; Wwise handles the transition with no bespoke scripting.
  • Gameplay-first attenuation. Grenadier footsteps stay audible at 75 m for threat awareness while box debris collapses at 11 m, keeping the mix tidy.
  • Mix-ready reverb control. Designers ride Reverb_* RTPC sliders (Cave, StoreRoom, Stone Big/Small) directly in-editor instead of requesting code tweaks.
  • Right-size compression. Music stays at Vorbis Q8, ambience Q7 prevents loop artifacts, SFX sit at Q5, and UI uses low quality Vorbis to save disk.

Systems delivered

  • SC_AMB state mappings for Jungle, Main Chamber, and Building layers, plus AMB_Addition loops for secondary textures.
  • Material + locomotion footstep switches (SWC_Footsteps, SWC_Ellen_Land) supply per-surface variation with Random Containers.
  • Enemy audio (Chomper, Grenadier, Teleporter) uses 3D positioning, cone attenuation, and dedicated aux sends for spatial clarity.
  • Unity scripts rely on AkState, AkSwitch, and AkRTPCManager so design changes propagate to Wwise without bespoke code.

Project 03 · Multi-platform

Stomach Aches

FPS platformer set inside a human body. Built with Wwise 2024.1.2.8726 + Unity C# API to target Windows, Mac, Android, and Android_Low devices with strict RAM budgets.

Zone-based banks Android_Low profile Silence plugin RTPC waterfall
Evidence: JSON

Snapshot

Platforms
Windows · Mac · Android · Android_Low (dedicated soundbank directories)
Soundbank plan
Init + General stay loaded; Brain (670 KB), Mouth (384 KB), Stomach (2.8 MB), and Music banks load on demand.
Runtime footprint
~10–15 MB (General ≈10 MB + active zone 1–3 MB) according to memory profile.
Key scripts
WwiseStateBridge.cs, WaterfallDistanceRTPC.cs, SurfaceIdentifier.cs, RandomAreaWwise.cs, SneezeProjectile.cs.

Impact

  • Zone loading saves RAM. WwiseStateBridge swaps Brain/Mouth/Stomach banks as the player moves, saving ~3.8 MB versus keeping every zone resident.
  • Sculpted waterfall mix. DistanceToWaterfall RTPC crossfades Splashes_Close (130 KB, 0–10 m), Main_Mid (6.3 MB, 10–50 m), and Rumbling_Far (3.6 MB, 50+ m) with per-frame updates from WaterfallDistanceRTPC.cs.
  • Silence plugin efficiency. Brain and Mouth ambiences use Wwise Silence sources for timing gaps, trimming ~80% of the memory silent WAVs would consume.
  • Streaming where it counts. Brain_Song_Track streams from disk, so only ~220 KB of VO thoughts stay resident while music reads straight from storage.
  • No orphaned voices. SneezeProjectile caches playback IDs and calls StopPlayingID on destroy so looping snot projectiles never leak voices.

Systems delivered

  • WwiseStateBridge.cs routes Unity trigger colliders to GameStage states, which in turn load the correct zone bank and ambience.
  • SurfaceIdentifier.cs tags Gut, Thongue, and Skull materials; Controller.cs raycasts before each footstep to set the right switch.
  • RandomAreaWwise.cs spawns positioned one-shots inside configurable 3D volumes for organic zone details.
  • WaterfallDistanceRTPC.cs + SneezeProjectile.cs demonstrate explicit RTPC updates and StopPlayingID-based cleanup.

Glossary & cheat notes

Random Container

Wwise object that picks one asset from a pool each trigger—perfect for gunshots or footsteps so a single event covers every variation.

RTPC

Real-Time Parameter Control. Game code (WaterfallDistanceRTPC.cs) feeds live numbers to Wwise so the engine fades layers or reverb sends automatically.

Soundbank

Packaged bundle of events + audio. Keeping only Init + General resident and streaming the active zone keeps RAM predictable.

Silence plugin

Generates procedural silence inside Wwise containers. It replaces recorded blank audio and saves ~80% memory on gap-heavy ambiences.

Streaming

Large music or ambience files read from disk with a rolling buffer (e.g., Brain_Song_Track) instead of living entirely in RAM.

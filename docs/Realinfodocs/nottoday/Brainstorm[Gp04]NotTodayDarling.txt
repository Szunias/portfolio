Basic premise and goal of the game
Pvp racing game with grandmas where the goal is to escape death.  
The goal of the game is to race to the end of the track, while being pressured by a timed wall of death. If a player stays in the wall of death for too long, they are eliminated. Whoever gets to the end first, wins. Everybody else is automatically eliminated, so only one grandma can win. If everyone is eliminated, death wins. 
The feeling of the game is not very serious, though, the grandmas all understand and are not bitter about having to battle it out.

## Export to PDF

1. Otwórz `portfolio.html` w **Google Chrome** lub **Microsoft Edge**
2. Ctrl + P
3. **Destination:** Save as PDF
4. **Paper size:** A4
5. **Margins:** None
6. **Scale:** Default (100%)
7. **Options:** zaznacz **Background graphics** (inaczej nie będzie koloru)
8. Zapisz jako `Igor_Szuniewicz_Portfolio.pdf`

**20 stron, zero em/en-dashy, tekst dopasowany do voice motivation lettera.**
